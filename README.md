# English Reading Assistant 英语阅读助手

一个纯前端的英语阅读辅助工具。它可以把英文或中文文本渲染成可交互阅读页面，支持 AI 查词、句子/段落翻译、图片 OCR、文件导入、生词本和阅读历史。

![英语阅读助手总体功能](assets/overview.png)

## 适合做什么

英语阅读助手把“导入材料、专注阅读、查词翻译、积累生词、继续上次阅读”放在同一个单页里。它适合读英文文章、处理截图文字、整理生词，也适合把中文表达快速转成英文参考。

| 场景 | 你可以这样用 |
| --- | --- |
| 阅读英文文章 | 粘贴文章后直接点击单词查释义，双击翻译整句 |
| 处理截图或 PDF | 上传图片、PDF、DOCX、TXT，提取文本后继续阅读 |
| 写作与表达替换 | 切换到中译英模式，查询中文词语对应的英文表达 |
| 复习生词 | 收藏重要单词，导出 TXT / CSV 做后续记忆 |
| 长文继续阅读 | 自动保存历史记录，下次从右侧历史列表恢复 |

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 英文阅读 | 粘贴或导入英文文章后自动排版，点击单词查看音标和中文释义 |
| 中译英 | 粘贴中文文本，双击词语查英文表达，三击句子翻译整句 |
| 即时翻译 | 双击英文单词所在句子翻译整句，选中文本可翻译段落或片段 |
| 文件导入 | 支持图片、TXT、DOCX、PDF，可拖拽、点击选择或粘贴截图 |
| 图片 OCR | 使用 Tesseract.js 在浏览器中识别图片里的英文文本 |
| 生词本 | 收藏单词，右侧列表回看，支持导出 TXT / CSV |
| 阅读历史 | 自动保存最近阅读内容，可随时从侧栏继续阅读 |
| 本地存储 | API Key、生词本和历史记录保存在浏览器 localStorage 中 |

## 功能流程

```text
导入内容 → 自动排版 → 点击查词 / 翻译句段 → 收藏生词 → 导出复习
                      ↓
                   自动保存历史
```

核心界面分成三块：

- 顶部工具栏：切换“英文阅读 / 中译英”，配置 DeepSeek API Key。
- 中间阅读区：粘贴或导入内容，生成可点击、可翻译的阅读文本。
- 右侧侧栏：管理生词本和历史记录。

## 快速开始

1. 下载仓库中的 `English Reading Assistant.html`。
2. 双击该文件，用浏览器打开。
3. 在右上角 `API Key` 输入框填入 DeepSeek API Key。
4. 选择“英文阅读”或“中译英”，粘贴文本或导入文件即可使用。

> 查词和翻译需要网络连接，并会调用 DeepSeek API。文件解析、OCR、生词本和历史记录均在浏览器端完成。

## API Key 配置

1. 打开 [DeepSeek Platform](https://platform.deepseek.com/) 并登录。
2. 在 API Keys 页面创建一个以 `sk-` 开头的 Key。
3. 将 Key 粘贴到页面右上角的输入框。
4. 状态点变为绿色后即可开始查词和翻译。

API Key 会保存在当前浏览器的 localStorage 中。不要在公共电脑上长期保存自己的 Key。

## 英文阅读模式

1. 将英文文章粘贴到输入框，或通过上传区域导入文件。
2. 页面会自动把文章渲染成可交互段落。
3. 点击单词：查询音标和中文释义。
4. 双击任意单词：翻译该单词所在的整句。
5. 选中一段文本：自动翻译选中的内容。
6. 在释义弹窗中点击“收藏”：加入右侧生词本。

已缓存或已收藏的单词会有更明显的标记，方便回到文章中继续扫读。

## 中译英模式

1. 切换到“中译英”标签。
2. 粘贴中文文章。
3. 双击词语：查询对应英文表达。
4. 三击句子：翻译整句为自然英文。
5. 选中一段中文：翻译选中文本。

该模式适合写作、表达替换和把中文材料快速转换成英文表达。

## 文件导入

上传区域支持以下方式：

| 方式 | 说明 |
| --- | --- |
| 拖拽文件 | 将文件拖入上传区域 |
| 点击上传 | 点击上传区域选择本地文件 |
| 粘贴截图 | 使用 `Ctrl+V` 直接粘贴截图 |
| 手动粘贴 | 将文本复制到输入框 |

支持格式：

| 格式 | 处理方式 |
| --- | --- |
| TXT | 直接读取纯文本 |
| DOCX | 使用 mammoth.js 提取文档文本 |
| PDF | 使用 pdf.js 逐页提取文字 |
| PNG/JPG/WebP | 使用 Tesseract.js 识别图片文字 |

## 生词本

右侧“生词本”会显示收藏的单词和简短释义。

- 点击生词：重新打开释义弹窗。
- 点击删除：移除单个单词。
- 导出 TXT：适合普通复习。
- 导出 CSV：适合导入 Anki、Excel 或其他词表工具。
- 清空：删除全部生词。

## 历史记录

输入或导入文章后，工具会自动保存最近 30 条阅读记录。

- 点击历史记录：恢复当时的阅读内容和模式。
- 删除单条记录：只移除该条历史。
- 清空历史：删除全部历史记录。

历史记录只保存在当前浏览器中，不会同步到服务器。

## 常见问题

### 这是单文件网页吗？

是。核心代码都在 `English Reading Assistant.html` 中，不需要安装或构建。

### 为什么查词或翻译失败？

常见原因包括：没有填写 API Key、Key 无效、账户余额不足、网络无法访问 DeepSeek API，或浏览器拦截了请求。

### API Key 会上传到第三方服务器吗？

页面只会把 Key 用于请求 DeepSeek API。Key 保存在浏览器 localStorage 中，不会上传到本项目自己的服务器，因为本项目没有后端服务器。

### 能离线使用吗？

部分功能不能离线使用。AI 查词和翻译需要 DeepSeek API；OCR、PDF、DOCX 等依赖 CDN 加载的前端库，首次使用也需要联网。

### 支持手机吗？

支持。页面已做响应式布局，手机上会把主阅读区和侧栏上下排列。
